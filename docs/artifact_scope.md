# Artifact Scope

This repository is a **public artifact package** accompanying the paper
*PromptCraft: Quantifying the Semantic-Syntactic Gap in LLM-Generated Smart Contract Tests through Multi-Provider Evaluation*.

It is **not** the complete private research codebase. The public release focuses on the minimum evidence needed to verify the paper's empirical claims:
- dataset and benchmark catalogs,
- released result tables corresponding to the paper,
- minimal public scripts that recompute selected summaries,
- evaluation rubrics and human-evaluation instructions,
- a small number of representative sample artifacts.
